# Retrieval-quality benchmarks (LongMemEval · LoCoMo · BEAM)

Standalone replay harnesses over the three standard agent-memory benchmarks —
no LLM judge, no API keys. All three ship gold evidence annotations, so
retrieval recall@k and NDCG are computed directly. Shared machinery
(extension loading, ranking conditions, metrics) lives in `common.py`; the
per-benchmark protocols live in one script each:

| script | benchmark | what it tests | license |
|---|---|---|---|
| `replay.py` | [LongMemEval](https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned) (500 q) | R+F prior under simulated usage; M mechanism demo | MIT |
| `locomo_eval.py` | [LoCoMo](https://github.com/snap-research/locomo) (~1.5k q, 10 convs) | **leakage-free M**: sequential QA, feedback from question k evaluated on k+1..n | CC BY-NC 4.0 |
| `ku_eval.py` | LongMemEval knowledge-update (78 q) | **forgetting**: oracle stale-fact penalty → update-preference | MIT |
| `beam_eval.py` | [BEAM](https://github.com/mohammadtavakoli78/BEAM) 128K tier (20 convs) | sequential feedback at longer context; short feedback streams | CC BY-SA 4.0 |
| `swe_eval.py` | [SWE-Bench-CL](https://github.com/thomasjoshi/agents-never-forget) (273 tasks, 8 repos) | coding experience-selection: retrieve related prior tasks, feedback per task (caveat: heuristic file-overlap gold links; SWE-ContextBench's factual links are unreleased) | MIT |

Embedder robustness: any script honors `RFM_EMBEDDER` (e.g.
`RFM_EMBEDDER=Qwen/Qwen3-Embedding-0.6B`); caches are per-model.

Exploratory M-variant studies (see script docstrings for protocols):
`signal_screen.py` (AUC of candidate value signals vs gold evidence),
`phase2_eval.py` (automatic answer-alignment outcomes vs oracle; cold-start
priors via a harness-side generalized shrink), and
`locomo_eval.py --feedback-batch G` (M's robustness to coarse feedback).

BEAM caveat (disclosed): its `source_chat_ids` evidence was generated by
GPT-4.1-mini during question construction (human-reviewed for question
validity), and skews toward user turns. LongMemEval: don't confuse
`longmemeval-cleaned` with `longmemeval-v2` (a different benchmark).

## Datasets

```sh
# LongMemEval (replay.py, ku_eval.py)
curl -sL -o data/longmemeval_s_cleaned.json \
  "https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned/resolve/main/longmemeval_s_cleaned.json"
# LoCoMo (locomo_eval.py)
curl -sL -o data/locomo10.json \
  "https://raw.githubusercontent.com/snap-research/locomo/main/data/locomo10.json"
# BEAM 128K tier (beam_eval.py)
for i in $(seq 1 20); do mkdir -p data/beam/$i
  curl -sL -o data/beam/$i/chat.json \
    "https://raw.githubusercontent.com/mohammadtavakoli78/BEAM/main/chats/100K/$i/chat.json"
  curl -sL -o data/beam/$i/probing_questions.json \
    "https://raw.githubusercontent.com/mohammadtavakoli78/BEAM/main/chats/100K/$i/probing_questions/probing_questions.json"
done
# STAR (star_eval.py — MIT; authored task flowcharts, real wizard IDs)
git clone --depth 1 https://github.com/RasaHQ/STAR data/star
# FloDial (flodial_eval.py — CDLA-Sharing-1.0; authored troubleshooting flowcharts)
git clone --depth 1 https://github.com/dair-iitd/FloDial data/flodial
# MultiDoc2Dial (md2d_eval.py — CC-BY-3.0; 488 authored gov documents)
curl -sL -o data/multidoc2dial.zip \
  "https://doc2dial.github.io/multidoc2dial/file/multidoc2dial.zip"
unzip -o -q data/multidoc2dial.zip -d data/ && rm data/multidoc2dial.zip
```

## Setup

```sh
uv venv --python 3.12 .venv        # needs enable_load_extension (not macOS system Python)
uv pip install --python .venv/bin/python sentence-transformers sqlite-vec numpy
curl -sL -o data/longmemeval_s_cleaned.json \
  "https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned/resolve/main/longmemeval_s_cleaned.json"
cargo build --release              # native dylib for this Python
.venv/bin/python replay.py --instances 500 --k 10 --feedback-demo
```

Embeddings (all-MiniLM-L6-v2, 384-dim) are cached in `cache/` after the first
run. Per-question outputs land in `results/per_question.jsonl`; the summary
table prints at the end. The protocol, conditions, and the reason the value
axis can't earn quality gains on this dataset (one labeled question per
instance) are documented in `replay.py`'s docstring and the main README.
